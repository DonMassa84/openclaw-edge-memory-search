# ADR-0001 — Repository Standard Baseline

## Status

Accepted

## Kontext

Die Repositories sollen nicht nur lauffähig, sondern reproduzierbar, auditierbar und portfoliofähig sein.

## Entscheidung

Jedes Repository erhält einen einheitlichen Mindeststandard:

- README
- Makefile
- Doctor Script
- Smoke Test
- Security Scan
- Runbook
- Architektur-Dokumentation
- Reproduzierbarkeits-Dokumentation
- Release-Prozess
- Projektabschluss-Checkliste

## Konsequenzen

Vorteile:

- schnellere Übergabe
- bessere Bewerbungs- und Portfolio-Wirkung
- geringeres Secret-Leak-Risiko
- klare Betriebsfähigkeit

Nachteile:

- initialer Dokumentationsaufwand
- pro Repo Nacharbeit nötig, wenn Speziallogik existiert
