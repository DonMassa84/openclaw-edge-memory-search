# Project Completion Checklist

## Pflicht

- [ ] README erklärt Zweck, Installation, Start und Tests.
- [ ] make doctor läuft.
- [ ] make setup ist definiert.
- [ ] make test oder Smoke-Test läuft.
- [ ] make security läuft.
- [ ] .env.example vorhanden.
- [ ] docs/ARCHITECTURE.md vorhanden.
- [ ] docs/RUNBOOK.md vorhanden.
- [ ] docs/REPRODUCIBILITY.md vorhanden.
- [ ] docs/SECURITY.md vorhanden.
- [ ] docs/RELEASE_PROCESS.md vorhanden.
- [ ] ADR vorhanden.
- [ ] Keine privaten Daten / Secrets / lokalen Pfade im Repo.
- [ ] Changelog gepflegt.
- [ ] Release-Check vor Push ausgeführt.

## Portfolio-Freigabe

- [ ] Demo ohne private Pfade.
- [ ] Screenshots sanitizt.
- [ ] Beispielausgaben anonymisiert.
- [ ] Projekt in 3 Sätzen erklärbar.
- [ ] Business-Nutzen dokumentiert.
